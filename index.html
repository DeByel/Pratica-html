6. Estrutura Semântica de Layout

Organize seu documento usando as tags semânticas para melhorar a legibilidade e SEO:

  • <header>: Contém o título e informações introdutórias.
  • <nav>: Define a seção de navegação (links para outras páginas).
  • <main>: O conteúdo principal da página (deve ser único).
  • <aside>: Conteúdo complementar, como barras laterais ou anúncios.
  • <footer>: Informações de rodapé, como direitos autorais e contatos.

Importante: A estrutura semântica não é apenas para humanos, mas também para mecanismos de busca e leitores de tela, melhorando a acessibilidade e o SEO do seu site.

Obs: Existem outros tipos de <rel> que são importantes dá uma averiguada, como esses aqui:

Principais Relacionamentos (Atributo rel)

  • Para <link> (links externos e recursos):
    • stylesheet: Vincula uma folha de estilo CSS.
    • icon: Define o favicon da página.
    • alternate: Indica uma versão alternativa do documento (ex: RSS feed, tradução).
    • canonical: Define a URL oficial para SEO, evitando conteúdo duplicado.
    • manifest: Vincula o manifesto do aplicativo da web (manifest.json).
    • author: Link para o autor do documento.
    • license: Link para a licença do conteúdo.
    • help: Link para ajuda ou documentação.
    • search: Link para uma página de busca.
  • Segurança em Links Externos (<a> com target="_blank"):
    • noopener: Impede que a nova página acesse window.opener, protegendo contra ataques de segurança.
    • noreferrer: Impede a passagem do cabeçalho Referer e age como noopener.
    • nofollow: Instrui motores de busca a não seguirem o link (útil para links pagos ou não confiáveis).
  • Performance e Pré-carregamento (<link>):
    • preload: Solicita que um recurso (fontes, scripts) seja baixado antecipadamente por ser crítico.
    • preconnect: Inicia a conexão com um servidor (DNS, TCP, TLS) antes da solicitação.
    • prefetch: Baixa recursos que podem ser necessários em navegações futuras.
    • dns-prefetch: Resolve o DNS de um domínio antecipadamente.
  • Navegação (<link>):
    • next: Indica o próximo documento em uma série (paginação).
    • prev: Indica o documento anterior em uma série (paginação).
    • first: Indica o primeiro documento em uma série.
    • last: Indica o último documento em uma série.

Esses atributos são cruciais para a estrutura, acessibilidade, segurança e SEO (Search Engine Optimization) de um site moderno.

Css: Trabalhando com estilos

1. Introdução ao CSS

CSS (Cascading Style Sheets) é a linguagem de estilos usada para controlar a aparência de um documento HTML. Ele permite separar o conteúdo (HTML) da apresentação (estilos), facilitando a manutenção e a consistência do design.

Exemplo de CSS:

/* Estilo para o corpo da página */
body {
    background-color: #f0f0f0; /* Cor de fundo */
    font-family: Arial, sans-serif; /* Fonte */
    color: #333; /* Cor do texto */
}

fontes

Para usar fontes personalizadas, utilize a regra @font-face:

@font-face {
    font-family: 'MinhaFontePersonalizada'; /* Nome da fonte */
    src: url('fonts/MinhaFontePersonalizada.woff2') format('woff2'); /* Caminho para o arquivo da fonte */
}

no uso em pratica: font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; que inclusive está nesse documento

Medidas

As medidas em CSS podem ser expressas em unidades absolutas (px, cm, in) ou relativas (em, rem, %, vw, vh).

Peso da fonte

O peso da fonte é controlado pela propriedade font-weight, que pode ser definida como um valor numérico (100 a 900) ou palavras-chave (normal, bold, bolder, lighter).

Obs: O peso da fonte pode variar dependendo da família de fontes utilizada, e nem todas as fontes suportam todos os pesos.

Shorthand

Propriedades de CSS podem ser combinadas usando a sintaxe abreviada (shorthand). Por exemplo, a propriedade margin pode definir as margens superior, direita, inferior e esquerda em uma única linha

no exemplo de fontes é usado a propriedade font para definir várias características da fonte em uma única declaração:

font: italic small-caps bold 16px/1.5 'Arial', sans-serif;

Como dito, nesse exemplo para as fontes, ela segue uma sequencia de: font-style -> font-weight -> font-size -> font-family, abaixo a mais exemplos.

  • font-style: Define o estilo da fonte (normal, italic, oblique).
  • font-variant: Define a variante da fonte (normal, small-caps).
  • font-weight: Define o peso da fonte (normal, bold, bolder, lighter ou valores numéricos de 100 a 900).
  • font-size: Define o tamanho da fonte (ex: 16px, 1em).
  • line-height: Define a altura da linha (ex: 1.5).
  • font-family: Define a família de fontes (ex: 'Arial', sans-serif).

Google Fonts

Para utilizar fontes do Google Fonts, basta adicionar o link para a fonte no cabeçalho do documento HTML:

<link href="https://fonts.googleapis.com/css2?family=Roboto:wght@300;400;700&display=swap" rel="stylesheet">

Em seguida, utilize a propriedade font-family para aplicar a fonte ao elemento desejado:

body {
                font-family: 'Roboto', sans-serif;
            }

formatos

Os formatos de fonte usando a regra @font-face mais comuns são:

  • .woff: Web Open Font Format, suportado por maioria das navegadores.
  • .woff2: Versão atualizada do WOFF, com melhor compressão.
  • .ttf: TrueType Font, amplamente suportado.
  • .eot: Embedded OpenType, usado principalmente para compatibilidade com o Internet Explorer.
  • .svg: Fontes em formato SVG, usadas principalmente para ícones e gráficos vetoriais.
  • .otf: OpenType Font, suporta recursos avançados de tipografia.

Exemplo

@font-face {
                font-family: 'MinhaFontePersonalizada';
                src: url('fonts/MinhaFontePersonalizada.woff2') format('woff2'),
             url('fonts/MinhaFontePersonalizada.woff') format('woff'),
             url('fonts/MinhaFontePersonalizada.ttf') format('truetype');
            }

Seletores

Seletores são usados para selecionar os elementos HTML que queremos estilizar. Existem vários tipos de seletores, como:

  • Seletores de Tipo: Selecionam elementos pelo nome da tag (ex: p, h1).
  • Seletores de Classe: Selecionam elementos por classe (ex: .minha-classe).
  • Seletores de ID: Selecionam um elemento único por ID (ex: #meu-id).
  • Seletores de Atributo: Selecionam elementos com base em atributos (ex: input[type="text"]).
  • Seletores de Pseudo-classe: Selecionam elementos em um estado específico (ex: a:hover para links quando o mouse está sobre eles).
  • Seletores de Pseudo-elemento: Selecionam partes específicas de um elemento (ex: p::first-line para estilizar a primeira linha de um parágrafo).

A Pseudo-classe merece uma atenção especial

As pseudo-classes permitem que você estilize elementos com base em seu estado ou posição. Alguns exemplos comuns incluem:

div:hover { background-color: lightgray; }

Box Model

O modelo de caixa (Box Model) é um conceito fundamental em CSS que descreve a estrutura de um elemento HTML. Ele é composto por quatro áreas:

  • Content: O conteúdo real do elemento (texto, imagens, etc.).
  • Padding: O espaço entre o conteúdo e a borda do elemento.
  • Border: A borda que envolve o padding e o conteúdo.
  • Margin: O espaço externo que separa o elemento de outros elementos.
  • border O espaço delimitado pela borda

A compreensão do Box Model é essencial para controlar o layout e a aparência dos elementos em uma página web.

Vários elementos dentro de uma página web são considerados boxes, sendo inline ou box-level

Tipos de caixas

box-level

usado principalmente com a tag div

Elementos que ocupam toda a largura disponível e começam em uma nova linha.

inline-level

usado principalmente com a tag span

Elementos que não começam em uma nova linha e ocupam apenas o espaço necessário.
